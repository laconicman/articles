This is a collaborative space for tech articles and notes.

## Purpose

- Share knowledge and insights on programming, tools, and technology
- Collaborate on articles through GitHub pull requests
- Build a lightweight, maintainable knowledge base

## How to Contribute

### Suggest a Topic

Open a [GitHub Issue](../../issues) with the `topic-idea` label.

### Write an Article

1. Fork the repository
2. Create a new file in `_drafts/` with your working title
3. Write using Markdown with YAML frontmatter
4. Submit a pull request when ready for review

### Article Format

```yaml
---
layout: post
title: "Your Article Title"
date: 2025-06-03 12:00:00 +0000
tags: [tag1, tag2]
lang: en  # or ru for Russian
draft: true  # remove when publishing
---

Your content here...
```

## Future: Bilingual Content

Plans to support both English and Russian (`en`/`ru`) through language-tagged posts.
